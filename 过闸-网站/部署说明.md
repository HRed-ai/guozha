# 《过闸》网站 · 部署说明

> 这是一个**纯静态网站**：没有后端、没有数据库、没有构建步骤。
> 把整个文件夹原样传上去就能用。

---

## 二、上线方式

### 方式 A：GitHub Pages（当前网络下唯一可用 · 免费 · 自动 https）

1. GitHub 新建仓库（**Public**）
2. 仓库页 → **Add file → Upload files**，把本文件夹的**全部内容**拖进去
   （不是拖文件夹本身；**确认 `.nojekyll` 在列表里**）→ Commit
3. **Settings → Pages** → Source 选 `Deploy from a branch`
4. Branch 选 `main`，文件夹选 `/ (root)` → **Save**
5. 等 1 分钟（顶部 **Actions** 出绿色勾）
6. 得到 `https://用户名.github.io/仓库名/`

> **Cloudflare 在本机网络下不通**：实测 `*.workers.dev` 被 DNS 污染到 Facebook 的 IP，
> `*.pages.dev` 与 `cloudflare.com` 的 TLS 也全部超时。所以不要用 Cloudflare 系。
> 若以后绑自有域名，优先找国内可达的托管（或国内主机 + 备案）。

### 方式 B：自己的服务器 / 对象存储

- **Nginx**：把目录指过去即可，注意给 `.webmanifest` 配 `application/manifest+json`、给 `.js` 配 `text/javascript`
- **阿里云 OSS / 腾讯云 COS**：静态网站托管，但**默认域名访问 html 会强制下载**，必须绑定自定义域名；国内域名还要 **ICP 备案**
- **务必启用 https**：PWA 安装、Service Worker、Web NFC 都要求安全上下文

## 三、本地预览（改完先看效果）

装了 Node 的话，在文件夹里执行：

```
node serve.js 8088
```

然后浏览器打开 <http://127.0.0.1:8088/>。手机在同一 Wi-Fi 下可以用
`http://电脑局域网IP:8088/` 打开。

> 没有 Node 也可以用任意静态服务器，例如 `python -m http.server 8088`。

## 四、绑定自己的域名（免备案）

1. 买域名（阿里云 / 腾讯云 / Namecheap，`.cn` 约 30 元/年，需实名）
2. 在 Cloudflare「添加站点」，拿到两个 NS 地址
3. 回域名商把 **DNS 服务器改成 Cloudflare 的**
4. Cloudflare Pages 项目 → **Custom domains** → 填你的域名 → 自动配 CNAME 与证书
5. 1–5 分钟生效，`https://你的域名` 即可用

> 域名指向境外托管**不需要备案**；指向国内服务器才需要（1–3 周）。建议一次买 3–5 年并开自动续费。

## 五、NFC 标签怎么写

- 写入内容：`https://你的域名/#s03`（第几闸就换 `#s0几`）
- 用手机 App **NFC Tools**（iOS / 安卓都有）写 NDEF URI 记录即可
- 标签类型：Type 2（NTAG213 的 144 字节完全够）
- **先烧 1 枚**，用 iPhone 和安卓各测一台，确认能直接打开页面，再批量烧剩下 7 枚
- 域名定了再烧 —— 换域名要逐枚重写

## 六、更新网站时

1. 改完文件
2. **在本文件夹执行 `node bump.js`** —— 它会自动把 `sw.js` 里的版本戳改成当前时间
   ```
   旧版本： const VERSION = 'guozha-20261025-1607';
   新版本： const VERSION = 'guozha-20261025-1637';
   ```
3. 把改动过的文件重新上传（同名覆盖）→ Commit
4. 手机端如果还是旧版：关掉标签页重新打开，或在系统里清一下该站点数据

> 为什么必须改：浏览器只在 `sw.js` 内容变化时才更新缓存；版本号不变，读者可能一直看旧版。
> 忘了手改没关系，跑一次 `node bump.js` 就行。

## 八、两个已知限制

1. **进度按域名隔离**：`localStorage` 绑定访问地址，换域名后进度不跟随。旧进度可用**文牒码**迁移（单闸页日历下方「恢復」，输入如 `澄谢龙`）。
2. **自建闸存在浏览器里**：清空浏览器数据会丢。重要内容请用「匯出」存一份 JSON，换设备时「匯入」。
